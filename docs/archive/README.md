# Archive

Files from the original LOKA repository, kept unchanged for transparency and moved out of the active tree when this public copy was made (see `docs/IMPORT-SCRUB.md`).

- `security-reviews/`: internal design reviews written while LOKA was built (Oct 2-6 2026). The ones that name a reviewer name the AI coding agent, and most say in their own text that they are not an independent audit. None is an independent security audit, and nothing in this repository relies on them.
- `LOKA-AGENTS-original.md`: LOKA's original instruction file for coding agents. The active build guide is `AGENTS.md` at the repository root.
